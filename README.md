# Line Drawing Algorithms

These are my line drawing labs from the CSE423 Computer Graphics course at BRAC University. I did them in 2021, in my B.Sc. in Computer Science and Engineering. The code is in Java with JOGL, which is OpenGL for Java.

## What is inside

| Folder | What it does |
|---|---|
| `lab1-lines` | Draws lines and shapes with OpenGL points |
| `lab2-dda-line-drawing` | Uses the DDA line algorithm to draw the digits of my student ID |
| `lab3-midpoint-line-drawing` | Uses the midpoint line algorithm to draw the digits of my student ID |
| `lab4` | One more drawing task with points |

Every folder has a screenshot of the output. `lab1-lines/Line.java` is based on the JOGL starter code from the course.

## How to run

Step 1: Install Java 8 or newer.

Step 2: Add the JOGL jars (`jogl-all.jar`, `gluegen-rt.jar` and their native jars) to the classpath.

Step 3: Compile and run the lab file.
